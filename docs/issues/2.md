Record CH91 and download an MP4

## Parent

Project specification: #1

## What to build

Deliver the first complete recording path on a Linux Docker host: preview CH91, start and stop capture from the UI or API, finalize a compatible source into one MP4, and download it from a persistent recordings list. Include local Docker Compose deployment and deterministic acceptance tests; image publication comes later.

Implement this as an end-to-end slice, including persistent state, API, interface, and observable tests where applicable. Parent specification #1 governs the confirmed requirements; do not close or edit it.

## Acceptance criteria

- [ ] Compose starts a usable application with persistent settings, session metadata, and media storage; replacing an idle container retains history and completed recordings.
- [ ] Initial source is https://ch91.gvsit.org/hls/test.m3u8. A live preview works independently of recording and closing the browser does not stop capture.
- [ ] UI and documented API provide start, stop, status, list/detail, and completed MP4 download. Start returns a stable recording ID.
- [ ] One session occupies admission through capture and processing. Concurrent starts and starts during processing receive clear busy responses and never spawn overlapping sessions.
- [ ] Stopping produces a playable MP4 containing video/audio when available, remuxing compatible H.264/AAC without unnecessary re-encoding.
- [ ] Filename is based on the original start date/time using a documented filesystem-safe format and timezone; final downloads appear only after validated successful completion.
- [ ] UI and API expose Recording, Processing, Ready, and actionable Error states. Basic failures preserve captured media rather than silently removing it.
- [ ] API acceptance tests use an isolated local HLS fixture and storage, verify playable output and admission races, and include a browser smoke test and Compose smoke test.
- [ ] No built-in authentication is added. Document that deployment must restrict all access through operator-managed Cloudflare Access or another trusted boundary.
