# #30: Optional automatic uploads with metadata templates

## Parent

Specification: #21 — https://github.com/YaBoiSean319/stream-recorder/issues/21

## What to build

Enable unattended uploads for future successful recordings with templates/defaults and per-recording automation overrides.

Include applicable persistent state, API, GUI, documentation, and observable tests as one complete slice. Follow the parent specification and glossary; do not close or modify the parent issue.

## Acceptance criteria

- [ ] Administrator Settings enable automatic upload, disabled by default, with editable visibility, tags/category/audience/notification defaults and title/description templates.
- [ ] Resolve templates from recording title, source name, and original start date/time with documented neutral source-name fallback, formatting, and validation.
- [ ] Upload only future successfully finalized recordings; never backfill existing recordings or automatically enqueue interrupted/recovered sessions.
- [ ] Per-recording automation overrides metadata through the API; snapshot resolved metadata once and prevent duplicate enqueue after restart/repeated completion.
- [ ] Use the same durable queue, audience gate, channel binding, idempotency, storage protection, and observable progress/link behavior as manual uploads.
- [ ] HTTP/local-HLS/provider/browser/restart tests cover enable/disable, eligibility, manual upload of recovered finalized footage, template resolution/invalid input, overrides, rename snapshots, and no backfill or duplicate work.
