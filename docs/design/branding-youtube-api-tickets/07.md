- [ ] Restrict connection/configuration to Administrators and expose /api/v1 configuration/status/auth-initiation/callback/disconnect operations with correct permission boundaries.
- [ ] Provide repository setup instructions for Google credentials/callback and document ordinary/Brand channel selection supported by the authorization flow.
- [ ] Local OAuth/provider HTTP fixtures and browser/restart tests cover connect, failed callbacks, refresh/reconnect need, disconnect, persistence, and no disclosure without real channel uploads.
